# 🚀 Simple CRUD API

A lightweight RESTful API that implements basic **Create, Read, Update, Delete (CRUD)** operations.
Built to demonstrate clean architecture, API design fundamentals, and scalable backend patterns.

---

## 📌 Features

- Create new records
- Retrieve single or multiple records
- Update existing records
- Delete records
- RESTful routing conventions
- Structured error handling
- Input validation
- Environment-based configuration

---

## 🏗️ Tech Stack

- Backend: FastAPI
- Database: MongoDB
- ORM/ODM: Mongoose
- API Testing: Postman

---

## ⚙️ Installation

```bash
# Clone repository
git clone https://github.com/your-username/simple-crud-api.git

# Navigate to project
cd simple-crud-api

# Install dependencies
npm install

# Server run on:
http://localhost:5000
```
